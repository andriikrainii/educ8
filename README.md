# Навчальний центр — розгортання на Netlify

Веб-додаток із денними уроками для двох учнів (Юра, Світлана), окремим батьківським розділом, обліком часу / вставлень / правок і **синхронізацією між пристроями** через власний бекенд.

## Що всередині

```
netlify-app/
├── index.html                     # весь інтерфейс і логіка (фронтенд)
├── netlify/functions/state.mjs    # бекенд: зберігання й злиття результатів (Netlify Blobs)
├── netlify.toml                   # конфіг: маршрут /api/state → функція
├── package.json                   # залежність @netlify/blobs
└── README.md                      # цей файл
```

Дані зберігаються у **Netlify Blobs** (вбудоване сховище Netlify — окремі сервіси чи БД не потрібні). Фронтенд звертається до `/api/state`: `GET` — завантажити, `POST` — зберегти (сервер зливає дані з усіх пристроїв, нічого не втрачаючи).

## Розгортання — варіант 1: через GitHub (рекомендовано)

1. Створіть новий репозиторій на GitHub і завантажте туди **вміст** папки `netlify-app` (щоб `index.html` і `netlify.toml` були в корені репозиторію).
2. У Netlify: **Add new project → Import an existing project → GitHub**, оберіть цей репозиторій.
3. Налаштування збірки лишіть за замовчуванням (Publish directory: `.`; Build command можна лишити порожнім). Натисніть **Deploy**.
4. Netlify сам встановить `@netlify/blobs`, розгорне функцію і видасть адресу виду `https://<назва>.netlify.app`.

Кожен `git push` оновлюватиме сайт автоматично.

## Розгортання — варіант 2: через Netlify CLI (без GitHub)

```bash
npm install -g netlify-cli
cd netlify-app
netlify login
netlify init        # створити новий проєкт у вашій команді
npm install         # підтягне @netlify/blobs
netlify deploy --build --prod
```

Локальна перевірка перед деплоєм: `netlify dev` — підніме сайт разом із функцією й Blobs на `http://localhost:8888`.

## Як користуватися

- Відкрийте адресу сайту. На вході — три кнопки: **Юра**, **Світлана**, **Батьки**.
- Учень проходить денний урок (відповіді вводить сам; наприкінці — звіт).
- Батьки заходять за PIN (створюється при першому вході) і бачать результати кожного учня: правильно/неправильно, час, «вручну/вставлено», кількість правок і прапорець «⚠ перевір».
- **Синхронізація**: усе зберігається на сервері, тож будь-який пристрій із цією адресою бачить актуальні результати (оновлення підтягуються автоматично раз на ~15 секунд).
- **Експорт**: у батьківському розділі кнопка «⬇ Експорт результатів» вивантажує файл `navchalnyy-rezultaty.json` — його можна надіслати Claude, щоб той проаналізував і склав наступні уроки.

## Безпека (важливо)

- PIN батьківського розділу — це **легкий замок** для розділення ролей на пристрої, а не криптозахист: дані лежать у сховищі й доступні за адресою `/api/state`. Не публікуйте адресу сайту широко.
- Для справжнього захисту (логін/пароль, приватний доступ) можна додати Netlify Identity або обмежити функцію токеном — скажіть Claude, і він допоможе це налаштувати.

## Додати нові уроки

Уроки — це масив `DAYS` у файлі `index.html` (шукайте `var DAYS=`). Кожен день має список питань; відкриті письмові завдання лежать в `OPEN`. Найпростіше — попросити Claude додати наступні дні за програмою: він згенерує оновлений `index.html`, який ви покладете в репозиторій.
